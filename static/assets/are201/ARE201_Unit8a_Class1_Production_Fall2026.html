You have seen this before · Unit 3

Diminishing marginal returns: Unit 3 named it

Diminishing marginal returns occur when, with technology and other inputs held constant, successive units of one input eventually generate smaller additions to total output.

Expand onto poorer land

The best-watered, most fertile parcels are planted first. The next 20 acres add less.

Crowd one machine

The first workers keep one harvester busy. Later workers wait, crowd, or duplicate tasks.

Pile on fertilizer

The first application lifts yields a lot. Later applications lift them less, then not at all.

Unit 3 named the idea. Today we measure it—with a table and a graph—and at the end of class we put a price on it.

Today's farm is the “crowd one machine” story, with numbers.

Background · what a firm does

A firm turns inputs into output

Production is the process of combining inputs to produce outputs—ideally output worth more than the inputs. A farm is a firm: it decides what to grow, how, how much, and how many people to hire.

Natural resources

Land, water, sweet potato slips

Labor

Harvest workers

Capital

The digger, the tractor, the trailer

Technology

When to dig, how to split the jobs

Entrepreneurship

The farmer who puts it all together

Economists call “technology” any method of combining inputs—not only gadgets. A better way to split jobs in the field is a change in technology.

You met the factors of production in Unit 2. Today we hold most of them fixed and change just one: labor.

Background · the time horizon

Short run vs. long run

Short run

At least one input is fixed.

Pine Hollow, this harvest: one digger, and the field is already planted. Only the number of workers can change.

Long run

All inputs can change.

Next year: lease a second digger, plant more acres, build a bigger curing room—or sell the farm.

Fixed input

Cannot be changed quickly: the digger lease, the planted field, the building.

Variable input

Can be changed quickly: workers, diesel, boxes, fertilizer.

The long run is not a date on the calendar. It is “long enough to change every input.” For a food truck that might be weeks; for an orchard, years.

The production function works like Unit 7’s utility table

A production function shows how much output a firm gets from its inputs. In the short run we change only one input—labor—and hold the rest fixed.
Unit 7 · the consumerUnit 8a · the firm
Total utility (TU)Total product (TP): total output
Marginal utility: MU = ΔTU ÷ ΔQMarginal product: MP = ΔTP ÷ ΔL
Diminishing marginal utilityDiminishing marginal returns
MU is the slope of TUMP is the slope of TP
Marginal product of labor (MP): the extra output from hiring one more worker, holding the other inputs fixed.

LO 8a.1 · game debrief

Game debrief: where—and why—MP fell

Workers in hiring order: Maria 40 · Jamal 60 · Kenji 50 · Priya 30 · Luis 20 · Hannah 10 · Omar −10

1
Where did diminishing returns begin? Worker #3, Kenji: MP fell 60 → 50, the first MP smaller than the one before. On the graph, that is where TP starts to flatten.
2
Why did MP rise, then fall? Jamal let Maria specialize, so MP rose. After that everyone shared one digger, a fixed input—not lazier workers. Any hiring order gives the same numbers.
3
When MP fell, did total output fall? No. TP kept rising (150 → 210) while MP shrank. Only a negative MP—Omar’s −10—made TP fall, 210 → 200.
4
Does MP always rise first? No. Rise-then-fall is the typical shape; the law only says MP eventually falls—sometimes from the very first unit, as the fertilizer exercise will show.

Change a fixed input and the whole curve moves

Second curve is illustrative.

More capital

Next season Pine Hollow leases a second digger. The same crews now dig more, and MP starts to fall later.

Different technology

Organic dairies cannot use growth hormones, so the same cows and feed give less milk: the organic production function sits lower.
